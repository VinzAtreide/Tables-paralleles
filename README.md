# Tables Parallèles

Carnets d'un MJ qui mène plusieurs mondes de front — https://tablesparalleles.fr

Site statique généré par [Hugo](https://gohugo.io), publié sur GitHub Pages.
Newsletter : [Buttondown](https://buttondown.com/tablesparalleles).

## Publier un article

1. Créer `content/posts/mon-titre.md` avec le frontmatter habituel
   (`title`, `date`, `description`, `serie`, `slug`).
2. `draft: true` tant qu'il n'est pas prêt ; retirer la ligne pour publier.
3. `git push` — le site se reconstruit et se publie tout seul (~1 min).
